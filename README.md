# ShiftDeck

A work calendar and to-do list for the print & ship counter. Big buttons, animated, works offline.

- **Today** – greeting, progress ring, quick actions, next shift countdown, hours this week, today's schedule and to-dos
- **Calendar** – month view (swipe to change month), shifts / meetings / training / pickups / time off, weekly repeats
- **To-Do** – print orders with order #, customer and tap-to-call phone, priorities, swipe right to finish, swipe left to delete
- **Checklists** – one tap adds the Opening, Shift Change or Closing list to today (editable)
- Reminders as phone notifications, dark mode, backup / restore

All data stays on the phone.

## Install
Every push to the `shiftdeck` branch builds `ShiftDeck.apk` and attaches it to a `shiftdeck-N` Release. Open the Releases page on your phone, download `ShiftDeck.apk`, and allow installs from your browser when Android asks.
